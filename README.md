# BottradingfreebyTENMA

Koleksi Expert Advisor (EA) MetaTrader 5 siap pakai by **TENMA**.

## 📌 Cara Menggunakan di MetaTrader 5 (MT5):
1. **Unduh file `.ex5`** yang ingin Anda gunakan dari repository ini.
2. Buka aplikasi **MetaTrader 5** di PC / Laptop Anda.
3. Klik menu **File** -> **Open Data Folder**.
4. Buka folder: `MQL5` -> `Experts`.
5. **Salin dan tempel (paste)** file `.ex5` ke dalam folder `Experts` tersebut.
6. Di MetaTrader 5, buka jendela **Navigator** (tekan `Ctrl + N`), klik kanan pada folder **Expert Advisors**, lalu pilih **Refresh**.
7. Drag bot pilihan Anda ke chart MT5, dan pastikan opsi **Algo Trading** (Auto Trading) dalam keadaan aktif.

> 🔒 **Keamanan & Lisensi:** Seluruh bot disediakan dalam format binary (`.ex5`) resmi MetaTrader. Pengguna dapat langsung memasang dan menjalankannya tanpa perlu melakukan kompilasi ulang di MetaEditor.
